# Voidbox Launcher

[English](README.md) | [Русский](README.ru.md) | **Українська**

Безкоштовний легкий лаунчер Minecraft, зроблений під збірки: перетягніть збірку й натисніть «Грати». Без реклами та без стеження.

## Завантажити

1. Відкрийте [останній реліз](https://github.com/Hebbyk/voidbox-launcher/releases/latest).
2. Завантажте інсталятор `.msi` і запустіть його.

Поки що лише для Windows.

> **Попередження SmartScreen:** інсталятор поки не підписаний цифровим підписом, тому Windows може показати «Windows захистила ваш ПК». Натисніть **Докладніше → Усе одно виконати**.

## Можливості

**Збірки та Java**
- **Імпорт збірок трьох основних форматів**: Modrinth (`.mrpack`), CurseForge (`.zip`) і Packwiz (`pack.toml`), зокрема віддалені індексні файли для автооновлення збірок.
- **Java без клопоту**: добирає потрібну версію Java для кожної версії Minecraft і завантажує її, якщо її немає.

**Догляд за екземпляром**
- **Перевірка модів**: знаходить дублікати, читаючи справжній ID і версію кожного мода, видаляє стару копію та попереджає, якщо моду потрібен новіший NeoForge, ніж в екземплярі.
- **Оновлення модів**: впізнає кожен мод за хешем файлу на Modrinth (і на CurseForge, якщо є ключ API), оновлює лише позначені та зберігає старий файл, щоб **скасування** могло його повернути. Бета-версії ніколи не вибираються наперед.
- **Зміна версії**: переводить екземпляр на іншу версію Minecraft на місці, з точкою відкату та копією світів за бажанням. Найкраще працює для збірок із звичайних модів; збірка, побудована навколо власних модів, зазвичай не переноситься, доки автор її не оновить.
- **Вмикання й вимикання модів** без видалення.
- **Імпорт світів** із застосунку CurseForge, офіційного лаунчера або будь-якої теки. Світи копіюються, а не переносяться.
- **Дублювання екземпляра** разом зі світами.
- **Допомога при вильотах**: якщо гра закрилася з помилкою, лаунчер показує справжні рядки помилки з логу та кнопки «Копіювати» й «Відкрити теку».

**Основне**
- **Інтерфейс англійською, російською та українською.**
- **Вхід через Microsoft та ely.by.**
- **Перевірка оновлень** через GitHub Releases.
- **Без реклами та без стеження.**

## Щось пішло не так?

Запитайте в каналі `#help` на [Discord](https://discord.gg/xH3Rg4vKNb) або створіть [Issue](https://github.com/Hebbyk/voidbox-launcher/issues) і додайте лог гри. Вставте цей шлях в адресний рядок Провідника:

```
%LOCALAPPDATA%\MCLauncher\instances\<назва збірки>\minecraft\logs\latest.log
```

**Запуск із вихідного коду** (Windows, Python 3, звичайний термінал без прав адміністратора):

```
py -m pip install -r requirements.txt
py gui.py
```

**Збирання інсталятора** (потрібні .NET SDK і WiX):

```
.\build.ps1 -Version 1.2.3
```

MSI з'явиться в теці `dist\`.

**Ключ CurseForge:** у вихідному коді немає ключа API. Лаунчер попросить його під час імпорту збірки CurseForge (безкоштовний ключ можна отримати на [console.curseforge.com](https://console.curseforge.com)). Щоб вбудувати власний ключ у збірку, запустіть `py make_key.py` перед збиранням.
