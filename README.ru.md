# Voidbox Launcher

[English](README.md) | **Русский**

Бесплатный лёгкий лаунчер Minecraft, сделанный под сборки: перетащите сборку и нажмите «Играть». Без рекламы и без слежки.

## Скачать

1. Откройте [последний релиз](https://github.com/Hebbyk/voidbox-launcher/releases/latest).
2. Скачайте установщик `.msi` и запустите его.

Пока только для Windows.

> **Предупреждение SmartScreen:** установщик пока не подписан цифровой подписью, поэтому Windows может показать «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.

## Возможности

**Сборки и Java**
- **Импорт сборок трёх основных форматов**: Modrinth (`.mrpack`), CurseForge (`.zip`) и Packwiz (`pack.toml`), включая удалённые индексные файлы для автообновления сборок.
- **Java без забот**: подбирает нужную версию Java для каждой версии Minecraft и скачивает её, если её нет.

**Забота об экземпляре**
- **Проверка модов**: находит дубликаты, читая настоящий ID и версию каждого мода, переносит старую копию в папку `disabled_mods` (ничего не удаляется) и предупреждает, если моду нужен более новый NeoForge, чем в экземпляре.
- **Обновление модов**: опознаёт каждый мод по хэшу файла на Modrinth (и на CurseForge, если есть ключ API), обновляет только отмеченные и сохраняет старый файл, чтобы **отмена** могла его вернуть. Бета-версии никогда не выбираются заранее.
- **Смена версии**: переводит экземпляр на другую версию Minecraft на месте, с точкой отката и копией миров по желанию. Лучше всего работает для сборок из обычных модов; сборка, построенная вокруг собственных модов, обычно не переносится, пока автор её не обновит.
- **Включение и отключение модов** без удаления.
- **Импорт миров** из приложения CurseForge, официального лаунчера или любой папки. Миры копируются, а не переносятся.
- **Дублирование экземпляра** вместе с мирами.
- **Помощь при вылетах**: если игра закрылась с ошибкой, лаунчер показывает настоящие строки ошибки из лога и кнопки «Копировать» и «Открыть папку».

**Основное**
- **Интерфейс на английском и русском.**
- **Вход через Microsoft и ely.by.**
- **Проверка обновлений** через GitHub Releases.
- **Без рекламы и без слежки.**

## Что-то пошло не так?

Спросите в канале `#help` на [Discord](https://discord.gg/xH3Rg4vKNb) или создайте [Issue](https://github.com/Hebbyk/voidbox-launcher/issues) и приложите лог игры. Вставьте этот путь в адресную строку Проводника:

```
%LOCALAPPDATA%\MCLauncher\instances\<имя сборки>\minecraft\logs\latest.log
```

## Открытый исходный код

Voidbox Launcher — свободное ПО под лицензией [GNU GPL v3](LICENSE). Copyright (c) 2026 Hebby. Код можно читать, менять и распространять, если ваша версия остаётся под GPL, сохраняет уведомление об авторстве и публикует свой исходный код.

**Запуск из исходников** (Windows, Python 3, обычный терминал без прав администратора):

```
py -m pip install -r requirements.txt
py gui.py
```

**Сборка установщика** (нужны .NET SDK и WiX):

```
.\build.ps1 -Version 1.2.3
```

MSI появится в папке `dist\`.

**Ключ CurseForge:** в исходниках нет ключа API. Лаунчер попросит его при импорте сборки CurseForge (бесплатный ключ можно получить на [console.curseforge.com](https://console.curseforge.com)). Чтобы встроить свой ключ в сборку, запустите `py make_key.py` перед сборкой.
